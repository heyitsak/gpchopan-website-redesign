# 🏛️ Government Polytechnic Chopan — Website Redesign & Palette Hub

A comprehensive design suite and multi-theme institutional website exploration for **Government Polytechnic Chopan, Sonbhadra (U.P.)**.

## 🎨 Theme Palettes & Variations

- **Palette 1: Bharat Tech** (`palette-1-bharat-tech`) — Contemporary Indian academic aesthetic with deep saffron, navy, and clean ivory accents.
- **Palette 2: Premier IIT/NIT** (`palette-2-premier-iit-nit`) — Prestigious engineering institute motif with royal blue, slate, and crisp typography.
- **Palette 3: High-Tech Digital** (`palette-3-high-tech-digital`) — Modern cyber-educational layout with dark-mode elements and vibrant cyan/electric indigo accents.
- **Palette 4: Green Energy Campus** (`palette-4-green-energy-campus`) — Sustainable and eco-conscious engineering motif with emerald, jade, and earthy neutrals.
- **New Site Golden Edition** (`new site golden`) — Premium ceremonial edition featuring gold trim, high-contrast badges, and rich heraldry.
- **New Site v1 & v2** (`new site v1`, `new site v2`) — Iterative responsive institutional portal architectures.
